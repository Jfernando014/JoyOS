# JoyOS v7

Lanzador e interfaz automotriz para Chevrolet Joy 2022.

Diseñado para unidad principal Android de 9 pulgadas (`1024×600`, MediaTek `AC8227L`).

## Estructura
- `prototype_v7_joy.html`: Interfaz del sistema (Cockpit, Música, Mapa, Ajustes, Apps y perfiles).
- `Logov2.png`, `Logov2_mono.png`, `zxdzlogo.png`: Logos y recursos gráficos.
